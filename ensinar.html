Ensinar a Ngola

Cola uma aula, a página converte-a em trechos da biblioteca no teu navegador (nada é enviado para lado nenhum) e dá-te os ficheiros para carregares na pasta livros/ do GitHub. Não precisa de Python.
Dica para o código Python: copia a aula da fonte original usando o botão "copiar" do bloco de código. Copiar o texto à mão perde o recuo, e em Python isso muda o significado. Se o recuo for reconstruído automaticamente, a página avisa e a Ngola mostra o aviso nas respostas.

Depois de descarregar: entra na pasta livros/ do GitHub, Add file → Upload files, arrasta os dois ficheiros (substituem os antigos) e espera o ✅ verde.
